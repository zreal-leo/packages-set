## fmt-init

快速初始化项目代码格式化配置，支持 prettier 和 oxfmt。详细使用请参考 [fmt-init](packages/fmt-init/readme.md)

## console-temp

扩展 console.temp 用于临时日志记录，并提供一个 bin 来删除所有临时日志。详细使用请参考 [console-temp](packages/console-temp/readme.md)

## branch-helper

支持创建 git 分支，同时将分支和备注记录到 branch.log 文件中。详细使用请参考 [branch-helper](packages/branch-helper/readme.md)
